# Автоучёт трат: чек-лист для Google Play

## 1. Декларация доступа к уведомлениям

Приложение использует `NotificationListenerService` (доступ выдаётся пользователем в системных настройках). Если Play Console запросит обоснование, используйте формулировку:

> Bud-Jet is a personal expense tracker. Its core feature "Automatic tracking" reads payment notifications from banking and payment apps that the user explicitly selects, to add expenses without manual entry. Notifications are processed only on the device; their content is never transmitted. The feature is optional: the app is fully usable with manual entry, and the user is shown an explanation screen before being sent to system settings.

Проверьте текущие требования Play Console для вашего приложения: списки разрешений, требующих декларации, меняются.

## 2. Data safety (Безопасность данных)

- Данные, которые **обрабатываются только на устройстве и не передаются**, по правилам Google не считаются «собираемыми». Автоучёт трат ничего не передаёт.
- Единственный сетевой запрос — курсы валют (open.er-api.com), передаются только коды валют.
- Ответы в форме должны совпадать с политикой конфиденциальности (`docs/privacy-policy.md`).

## 3. Политика конфиденциальности

Опубликуйте `docs/privacy-policy.md` (после правок) по публичной ссылке и укажите её в Play Console и в карточке приложения.

## 4. Листинг (черновик)

**Краткое описание (RU, до 80 символов):**
Траты считаются сами: из уведомлений банка. Или вручную — как удобно.

**Short description (EN, up to 80 chars):**
Expenses tracked for you from bank notifications — or add them manually.

**Полное описание (RU):**
Bud-Jet — простой учёт расходов, который работает за вас.

• Автоучёт трат: Bud-Jet сам добавляет покупки из уведомлений банков и платёжных приложений — сумма, продавец, дата. Обработка только на вашем телефоне.
• Ручной ввод за пару касаний — если не хотите давать доступ к уведомлениям.
• Категории и автокатегоризация по продавцу.
• Регулярные платежи: Bud-Jet находит подписки и показывает дату следующего списания.
• Аналитика по месяцам, лимиты по категориям, цели накоплений.
• Данные хранятся на устройстве; резервная копия и экспорт — по вашему желанию.

**Скриншоты (обновить):** главный экран с тратами, экран «Автоучёт трат», карточка «Регулярные платежи», онбординг «Считайте траты автоматически».

## 5. Тестирование перед релизом (Фаза 1–2)

- [ ] Онбординг: «Включить автоучёт» → объяснение → системные настройки → возврат → главный экран. «Пропустить» → главный экран, ручной ввод работает.
- [ ] Приложение банка появляется в «Приложения» после первого уведомления с суммой; после включения следующие траты добавляются сами (отметка «авто» в списке).
- [ ] Нераспознанная трата (например, в другой валюте) появляется в «Нужно подтвердить» и в уведомлении; «Добавить» открывает форму с суммой; «Пропустить» убирает её.
- [ ] Повторная отправка того же уведомления не создаёт дубль.
- [ ] Смена категории у авто-траты запоминается: следующая трата у того же продавца получает эту категорию.
- [ ] Перезагрузка телефона: автоучёт продолжает работать без открытия приложения.
- [ ] Samsung или Xiaomi с включённой оптимизацией батареи: оставить на ночь, проверить, что утренние траты пойманы; если нет — карточка батареи и предупреждение о тишине видны.
- [ ] Отключение доступа в настройках Android: статус «Выключен», приложение работает с ручным вводом.
- [ ] Регулярный платёж (3 списания с интервалом ~30 дней, или 2 одинаковых) появляется в «Регулярные платежи» с датой следующего списания.
- [ ] Обновление поверх старой версии: данные сохранены (миграции 2→5).
- [ ] Выпуск через поэтапное развёртывание (staged rollout) на небольшой процент.
