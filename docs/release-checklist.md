# Чеклист перед выпуском Bud-Jet (версия 8)

Отмечайте `[x]` по ходу проверки. Если пункт не проходит — пришлите скриншот или текст ошибки.

---

## 0. Сборка (обязательно первым)

- [ ] `./gradlew clean test` — все тесты проходят.
- [ ] `./gradlew bundleRelease` — AAB собирается без ошибок. Если нет — пришлите лог, это первое, что надо исправить.
- [ ] После сборки появилась папка `app/schemas` — закоммитьте её.
- [ ] `versionCode` больше, чем у версии в Google Play (сейчас 8).

## 1. Обновление поверх старой версии (самое важное)

Ошибка здесь = потеря данных у всех, кто уже установил приложение.

- [ ] Установите версию из Google Play (или прошлую сборку), добавьте несколько операций, цель, лимит.
- [ ] Установите новую сборку **поверх**, не удаляя старую.
- [ ] Приложение открывается, операции, цели и лимиты на месте, суммы те же.
- [ ] Категории переведены на язык приложения, ни одна не пропала.

## 2. Первый запуск (чистая установка)

- [ ] Экран 1: демо-анимация, «Пропустить» ведёт на главный экран.
- [ ] Экран 2: выбор валюты обязателен, цели выбираются.
- [ ] Экран 3 (Premium): видно цену и условия («Первый месяц — бесплатно, затем …»), текст не наезжает на кнопки.
- [ ] «Продолжить бесплатно — буду вводить вручную» → главный экран.
- [ ] Закрыть приложение на экране 2 и открыть снова → онбординг показывается заново.

## 3. Основные функции (без Premium)

- [ ] Добавить расход с суммой **«12,50»** (с запятой) и с точкой — оба сохраняются.
- [ ] Добавить доход. «В этом месяце» на главной показывает разницу **только за текущий месяц**.
- [ ] Нажатие на категорию на главной открывает добавление с уже выбранной категорией. Долгое нажатие — удаление с подтверждением.
- [ ] В окне добавления все категории видны (список прокручивается вбок).
- [ ] Редактирование операции: сумма, категория, заметка сохраняются; кнопка «Удалить» видна и спрашивает подтверждение.
- [ ] Операции: периоды неделя/месяц/год/свой; фильтр и поиск меняют и список, и итог.
- [ ] Аналитика: цвета категорий совпадают с цветами на главной и в операциях.
- [ ] Цели: цель накоплений показывает прогресс и «нужно X в день»; дедлайн показывает ту же дату, что выбрали; удаление цели спрашивает подтверждение.
- [ ] Лимиты: суммы с валютой, «осталось»/«превышено».
- [ ] Профиль → смена валюты с конвертацией: пересчитались операции, **начальный баланс, цель и лимиты**. Курс с запятой принимается.
- [ ] Смена языка (en/ru/es/pl): все тексты переведены, встроенные категории переименовались.
- [ ] Бэкап → сброс данных → восстановление из бэкапа: всё вернулось.
- [ ] Экспорт CSV без Premium показывает окно Premium.
- [ ] Напоминание в 20:00: приходит, если за день нет операций; нажатие открывает приложение.

## 4. Внешний вид

Каждый экран проверьте в **светлой и тёмной** теме.

- [ ] Главная, Операции, Аналитика, Цели, Профиль, Автоучёт, окно Premium, все нижние окна (добавление, фильтр, цель, лимит).
- [ ] Суммы доходов (зелёные) и расходов (красные) хорошо читаются на светлом фоне.
- [ ] Верхняя панель не под статус-баром и не слишком низко; нижнее меню и «+» не под панелью навигации.
- [ ] Профиль прокручивается до карточки Premium и «Сбросить данные».
- [ ] **Крупный шрифт**: Настройки телефона → Шрифт → максимум. Текст не обрезается, кнопки не наезжают.
- [ ] Если есть: маленький телефон (5–5,5") и телефон с жестами и с тремя кнопками навигации.

## 5. Premium-подписка

### 5.1 Быстрая проверка (отладочная сборка из Android Studio)
- [ ] Профиль → **долгое нажатие** на карточку Premium → «Тестовый Premium включён».
- [ ] Карточка показывает «Premium активен», автоучёт разблокирован, экспорт CSV работает.
- [ ] Выключить тестовый Premium тем же долгим нажатием → автоучёт снова предлагает подписку.

### 5.2 Настоящая покупка (обязательно до релиза)
Подготовка: подписка `budjet_premium` создана и активна в Play Console (`docs/google-play-subscription.md`), ваш аккаунт в «Тестирование лицензий», сборка установлена из **внутреннего тестирования**.

- [ ] Окно Premium показывает цену в вашей валюте и дату первого списания **до** нажатия кнопки.
- [ ] «Попробовать бесплатно — 30 дней» открывает окно Google Play с пробным периодом.
- [ ] После оплаты: карточка «Premium активен», автоучёт доступен, в онбординге — переход к доступу к уведомлениям.
- [ ] Закрыть и открыть приложение без интернета → Premium остаётся.
- [ ] «Управлять подпиской» открывает страницу подписок Google Play.
- [ ] Отменить подписку (у тестовых покупок период — несколько минут) → после окончания и перезапуска приложения автоучёт снова закрыт, ИИ-помощник выключен.
- [ ] Повторная попытка оформить: пробного периода больше нет, кнопка «Оформить за …».

## 6. Автоучёт трат (с Premium)

- [ ] «Включить» → объяснение → системные настройки → включить Bud-Jet → назад: статус «Включён».
- [ ] Перевод или покупка → приходит уведомление «Учитывать траты из …?» → включить приложение в «Приложения».
- [ ] Следующая покупка добавляется сама, с пометкой «авто» в списке операций.
- [ ] Неуверенная трата (например, в другой валюте) → «Нужно подтвердить» + уведомление; «Добавить» открывает форму с суммой; «Пропустить» убирает.
- [ ] Смена категории у авто-траты → следующая трата у того же продавца получает эту категорию.
- [ ] Журнал событий показывает, что происходило; «Проверить текст» работает.
- [ ] **Перезагрузка** телефона → покупка без открытия приложения всё равно добавилась.
- [ ] **Ночь на Samsung/Xiaomi**: утром покупка поймана. Если нет — отключить оптимизацию батареи через карточку на экране и повторить.
- [ ] Отозвать доступ в настройках Android → статус «Выключен», ручной ввод работает.
- [ ] «Регулярные платежи» на главной появляются после повторяющихся списаний (2 одинаковых с интервалом ~месяц).

## 7. ИИ-помощник

- [ ] По умолчанию выключен.
- [ ] Без Premium: включение → «ИИ-помощник доступен в Premium» + окно подписки, переключатель остаётся выключенным.
- [ ] С Premium: включение → окно согласия с описанием, что отправляется; «Отмена» оставляет выключенным.
- [ ] Выключение → «Хорошо, данные остаются только на устройстве…».

## 8. Play Console

- [ ] Подписка `budjet_premium`: базовый план на месяц + предложение «30 дней бесплатно» для новых клиентов, **активны**.
- [ ] Политика конфиденциальности (`docs/privacy-policy.md`, дописать e-mail и дату) опубликована по ссылке и указана в Play Console.
- [ ] **Безопасность данных**: заполнено по политике. Автоучёт работает только на устройстве; сетевой запрос — курсы валют; покупки — через Google Play.
- [ ] **Финансовые функции** (App content → Financial features): указать «личный учёт финансов / бюджет», без кредитов и платежей.
- [ ] Возрастной рейтинг, целевая аудитория (взрослые), «Реклама: нет».
- [ ] Если Play спросит про доступ к уведомлениям — текст из `docs/google-play-auto-capture.md`.
- [ ] Описание и скриншоты обновлены (автоучёт, Premium, регулярные платежи), черновики в `docs/google-play-auto-capture.md`.
- [ ] Выпуск: сначала внутреннее тестирование, затем production с **поэтапным развёртыванием** 10–20%, через 2–3 дня без проблем — 100%.

## Известные ограничения этой версии

- **Россия:** Google Play не принимает оплату из России — подписка там будет «недоступна».
- **Покупки проверяются только на устройстве** (кэш Google Play). Серверная проверка — вместе с бэкендом для ИИ.
- **После отмены подписки** автоучёт выключается при следующем открытии приложения, а не в момент окончания.
- **ИИ-помощник** — пока только переключатель и согласие; в окне Premium помечен «скоро».
