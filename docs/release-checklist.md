# Чеклист перед выпуском Bud-Jet (версия 9)

Отмечайте `[x]` по ходу проверки. Если пункт не проходит — пришлите скриншот или текст ошибки.

---

## 0. Сборка (обязательно первым)

- [ ] `./gradlew clean test` — все тесты проходят.
- [ ] `./gradlew bundleRelease` — AAB собирается без ошибок. Если нет — пришлите лог, это первое, что надо исправить.
- [ ] После сборки появилась папка `app/schemas` — закоммитьте её.
- [ ] `versionCode` больше, чем у версии в Google Play: в этой сборке 11 (в Play уже были 8 и выпуск PremiumInit). Если в Play есть 11 или больше — поднимите.

## 0.1 Релизная сборка с R8 (обязательно: включили обфускацию)

Отладочная сборка из Android Studio R8 не использует — проверять нужно **релизную**: из внутреннего тестирования Play или `./gradlew installRelease` (нужна подпись release).

- [ ] Приложение запускается, все вкладки открываются, онбординг проходит до конца.
- [ ] Добавить расход и доход, перезапустить приложение — операции на месте, типы (доход/расход) верные.
- [ ] **Обновление поверх прошлой версии**: старые операции читаются (тип операции хранится по имени — это первое, что ломает R8).
- [ ] Бэкап → восстановление, экспорт CSV, смена валюты с конвертацией.
- [ ] Окно подписки показывает цены из Google Play; тестовая покупка проходит.
- [ ] Автоучёт ловит уведомление; напоминание в 20:00 приходит.
- [ ] Если что-то падает — пришлите стек из Play Console (Android vitals → Сбои): он будет читаемым, файл сопоставления R8 входит в AAB.

## 1. Обновление поверх старой версии (самое важное)

Ошибка здесь = потеря данных у всех, кто уже установил приложение.

- [ ] Установите версию из Google Play (или прошлую сборку), добавьте несколько операций, цель, лимит.
- [ ] Установите новую сборку **поверх**, не удаляя старую.
- [ ] Приложение открывается, операции, цели и лимиты на месте, суммы те же.
- [ ] Категории переведены на язык приложения, ни одна не пропала.

## 2. Первый запуск (чистая установка)

- [ ] Экран 1: демо-анимация, «Пропустить» ведёт на главный экран.
- [ ] Экран 2: смена языка и темы применяется сразу, выбранная валюта при этом не сбрасывается; выбор валюты обязателен, цели выбираются; экран прокручивается на маленьком телефоне.
- [ ] Экран 3 (Premium): видно цену и условия («Первый месяц — бесплатно, затем …»), текст не наезжает на кнопки.
- [ ] «Продолжить бесплатно — буду вводить вручную» → главный экран → снизу выезжает окно «Напоминать о тратах?» (не системный диалог).
- [ ] После 3 добавленных вручную трат (при следующем возврате на главную) один раз выезжает окно «Считать траты автоматически?». Больше не повторяется.
- [ ] Закрыть приложение на экране 2 и открыть снова → онбординг показывается заново.

## 3. Основные функции (без Premium)

- [ ] Добавить расход с суммой **«12,50»** (с запятой) и с точкой — оба сохраняются.
- [ ] Добавить доход. «В этом месяце» на главной показывает разницу **только за текущий месяц**.
- [ ] Нажатие на категорию на главной открывает добавление с уже выбранной категорией. Долгое нажатие — удаление с подтверждением.
- [ ] В окне добавления все категории видны (список прокручивается вбок).
- [ ] Редактирование операции: сумма, категория, заметка сохраняются; кнопка «Удалить» видна и спрашивает подтверждение.
- [ ] Операции: периоды неделя/месяц/год/свой; фильтр и поиск меняют и список, и итог.
- [ ] Аналитика: цвета категорий совпадают с цветами на главной и в операциях.
- [ ] Цели: цель накоплений показывает прогресс и «нужно X в день»; дедлайн показывает ту же дату, что выбрали; удаление цели спрашивает подтверждение.
- [ ] Лимиты: суммы с валютой, «осталось»/«превышено».
- [ ] Профиль → смена валюты с конвертацией: пересчитались операции, **начальный баланс, цель и лимиты**. Курс с запятой принимается.
- [ ] Смена языка (en/ru/es/pl): все тексты переведены, встроенные категории переименовались.
- [ ] Бэкап → сброс данных → восстановление из бэкапа: всё вернулось.
- [ ] Экспорт CSV без Premium показывает окно Premium.
- [ ] Напоминание в 20:00: приходит, если за день нет операций; нажатие открывает приложение.

## 4. Внешний вид

Каждый экран проверьте в **светлой и тёмной** теме.

- [ ] Главная, Операции, Аналитика, Цели, Профиль, Автоучёт, окно Premium, все нижние окна (добавление, фильтр, цель, лимит).
- [ ] Суммы доходов (зелёные) и расходов (красные) хорошо читаются на светлом фоне.
- [ ] Верхняя панель не под статус-баром и не слишком низко; нижнее меню и «+» не под панелью навигации.
- [ ] Профиль прокручивается до карточки Premium и «Сбросить данные».
- [ ] Кнопки в одном стиле: главная — заливка, второстепенные — мягкая подложка, «Отмена» — серая, «Удалить» — красная мягкая. В окне добавления «Расход/Доход»: выбранная половина подсвечена, переключение работает.
- [ ] Кнопка «Сохранить» во время сохранения становится бледной (неактивной), а не остаётся яркой.
- [ ] **Телефон**: приложение по-прежнему только в портретной ориентации.
- [ ] **Планшет или складной телефон** (эмулятор Pixel Tablet / Pixel Fold): экран поворачивается. Поверните на каждом экране и с открытым нижним окном — ничего не падает, введённые данные не пропадают, вёрстка не разваливается. Сложить/разложить Fold — тоже.
- [ ] Профиль → Тема: «Как в системе / Светлая / Тёмная» переключают тему сразу и сохраняются после перезапуска.
- [ ] Все нижние окна «парят»: отступ снизу такой же, как по бокам, и они не заходят под панель навигации (жесты и три кнопки).
- [ ] **Крупный шрифт**: Настройки телефона → Шрифт → максимум. Текст не обрезается, кнопки не наезжают.
- [ ] Если есть: маленький телефон (5–5,5") и телефон с жестами и с тремя кнопками навигации.

## 5. Подписка: тарифы «Базовый» и Pro

### 5.1 Быстрая проверка (отладочная сборка из Android Studio)
- [ ] Профиль → **долгое нажатие** на карточку Premium → «Тестовый тариф: Базовый». Ещё раз — Pro, ещё раз — Бесплатный. (Карточку Pro в окне подписки видно, только если в `gradle.properties` указан адрес сервера.)
- [ ] **Базовый:** карточка «Тариф «Базовый» активен», автоучёт и экспорт CSV работают, ИИ-помощник — «Доступен в тарифе Pro»; включение открывает окно с выбранным Pro и кнопкой «Перейти на Pro».
- [ ] **Pro:** всё из «Базового» + ИИ-помощник включается (после согласия).
- [ ] **Бесплатный:** автоучёт снова предлагает подписку, ИИ-помощник выключен.

### 5.2 Настоящая покупка (обязательно до релиза)
Подготовка: подписки `bud_jet_base` и `bud_jet_premium` созданы и активны в Play Console (`docs/google-play-subscription.md`), ваш аккаунт в «Тестирование лицензий», сборка установлена из **внутреннего тестирования**.

- [ ] Окно Premium и экран 3 онбординга показывают **оба тарифа** с ценами в вашей валюте; выбор тарифа меняет условия и кнопку.
- [ ] Дата первого списания и цена видны **до** нажатия кнопки.
- [ ] «Попробовать бесплатно — 30 дней» открывает Google Play с выбранным тарифом и пробным периодом.
- [ ] После оплаты: карточка «Тариф … активен», автоучёт доступен, в онбординге — переход к доступу к уведомлениям.
- [ ] Базовый → Pro: Play показывает доплату, после неё доступен ИИ-помощник. Pro → Базовый: ИИ-помощник выключается.
- [ ] Закрыть и открыть приложение без интернета → тариф остаётся.
- [ ] «Управлять подпиской» открывает страницу подписок Google Play.
- [ ] Отменить подписку (у тестовых покупок период — несколько минут) → после окончания и перезапуска приложения автоучёт снова закрыт, ИИ-помощник выключен.
- [ ] Повторная попытка оформить: пробного периода больше нет, кнопка «… — цена/мес».

## 6. Автоучёт трат (любой тариф)

- [ ] «Включить» → объяснение → системные настройки → включить Bud-Jet → назад: статус «Включён».
- [ ] Перевод или покупка → приходит уведомление «Учитывать траты из …?» → включить приложение в «Приложения».
- [ ] Следующая покупка добавляется сама, с пометкой «авто» в списке операций.
- [ ] Неуверенная трата (например, в другой валюте) → «Нужно подтвердить» + уведомление; «Добавить» открывает форму с суммой; «Пропустить» убирает.
- [ ] Смена категории у авто-траты → следующая трата у того же продавца получает эту категорию.
- [ ] Журнал событий показывает, что происходило; «Проверить текст» работает.
- [ ] **Перезагрузка** телефона → покупка без открытия приложения всё равно добавилась.
- [ ] **Ночь на Samsung/Xiaomi**: утром покупка поймана. Если нет — отключить оптимизацию батареи через карточку на экране и повторить.
- [ ] Отозвать доступ в настройках Android → статус «Выключен», ручной ввод работает.
- [ ] «Регулярные платежи» на главной появляются после повторяющихся списаний (2 одинаковых с интервалом ~месяц).

## 7. ИИ-помощник (тариф Pro)

- [ ] По умолчанию выключен.
- [ ] Без Pro (бесплатно или «Базовый»): включение → «ИИ-помощник входит в тариф Pro» + окно подписки с выбранным Pro, переключатель остаётся выключенным.
- [ ] С Pro: включение → окно согласия с описанием, что отправляется; «Отмена» оставляет выключенным; «Включить» открывает экран «ИИ-помощник».
- [ ] В профиле нажатие на строку «ИИ-помощник» (когда он включён) открывает экран.
- [ ] Пока `budjet.apiBaseUrl` пустой: в окне подписки и онбординге только «Базовый», в профиле «ИИ-помощник: скоро». С адресом сервера появляется Pro; если сервер не отвечает — «Не удалось связаться с помощником…», приложение не падает.
- [ ] Вопрос длиннее 300 символов ввести нельзя; подсказки-вопросы отправляются по нажатию; поворот экрана не теряет разговор.
- [ ] Выключение → «Хорошо, данные остаются только на устройстве…», экран помощника больше не открывается.
- [ ] Профиль → «Политика конфиденциальности»: текст разбит на абзацы, есть раздел про ИИ-помощника.

## 8. Play Console

- [ ] Подписки `bud_jet_base` (2,99 $) и `bud_jet_premium` (Pro, 9,99 $): базовый план на месяц + предложение «30 дней бесплатно» для новых клиентов, **активны**.
- [ ] Политика конфиденциальности (`docs/privacy-policy.md`, дописать e-mail и дату) опубликована по ссылке и указана в Play Console.
- [ ] **Безопасность данных**: заполнено по политике. Автоучёт работает только на устройстве; сетевой запрос — курсы валют; покупки — через Google Play. Если сервер ИИ подключён — ещё сводка трат и id установки (см. `docs/google-play-subscription.md`, п. 4).
- [ ] **Финансовые функции** (App content → Financial features): указать «личный учёт финансов / бюджет», без кредитов и платежей.
- [ ] Возрастной рейтинг, целевая аудитория (взрослые), «Реклама: нет».
- [ ] Если Play спросит про доступ к уведомлениям — текст из `docs/google-play-auto-capture.md`.
- [ ] Описание и скриншоты обновлены (автоучёт, Premium, регулярные платежи), черновики в `docs/google-play-auto-capture.md`.
- [ ] Выпуск: сначала внутреннее тестирование, затем production с **поэтапным развёртыванием** 10–20%, через 2–3 дня без проблем — 100%.

## Известные ограничения этой версии

- **Россия:** Google Play не принимает оплату из России — подписка там будет «недоступна».
- **Покупки проверяются только на устройстве** (кэш Google Play). Серверная проверка — вместе с бэкендом для ИИ.
- **После отмены подписки** автоучёт выключается при следующем открытии приложения, а не в момент окончания.
- **ИИ-помощник** — экран, советы и чат готовы, но без сервера показывают «Сервис ИИ ещё не подключён». Заработает, когда впишете адрес в `gradle.properties` и поднимете бэкенд.
- **Сервер.** Пока `budjet.apiBaseUrl` в `gradle.properties` пустой, приложение никуда, кроме курса валют, не ходит — политика конфиденциальности и «Безопасность данных» верны. **Если впишете адрес сервера до релиза**, приложение начнёт отправлять токен покупки и id установки — тогда сначала обновите политику и форму «Безопасность данных».
- **R8 (сжатие кода) выключен.** Приложение работает, просто APK больше. Включать стоит отдельным релизом с полной проверкой, не сейчас.
